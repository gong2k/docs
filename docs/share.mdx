开源版 drawDB 编辑器可以把图表的快照发布出去，生成一个他人也能打开的链接。

## 创建分享链接

1. 打开图表。
2. 在菜单栏点击 `Share`（分享）。
3. 复制生成的链接。

URL 中会带一个 `shareId` 查询参数。当收件人打开时，drawDB 会下载该快照，并在其浏览器中保存一份**本地副本**。

<Callout title="分享不等于实时协作">
  开源版的分享链接传输的是一份快照。它不会让对方修改你本地的图表，也不会启动实时协作会话。drawDB Pro 提供了独立的团队权限与实时协作能力。
</Callout>

## 快照机制

分享操作会创建一个私有 GitHub Gist，里面存放图表 JSON。改完图后再点 Share，会刷新这个已发布的快照。收件人的本地副本不会与你保持同步。

<Callout title="私有 ≠ 已加密" type="warn">
  私有 Gist 不会被公开列出，但任何拿到 URL 的人都有机会访问其中的内容。不要在分享的图表里放私密或生产环境凭证。
</Callout>

在编辑器里点 `Unshare`（取消分享）可以立刻让已发布的快照失效。

## 配置嵌入链接

Share 对话框同时也会生成一个便于嵌入的 URL。选项可以让你：

- 选择初始的浅色或深色主题。
- 隐藏菜单栏、侧栏或工具栏。
- 强制这些控件始终对访客隐藏。

关于 Gist 的通用信息，请参阅 [GitHub Gist 文档](https://docs.github.com/en/get-started/writing-on-github/editing-and-sharing-content-with-gists/creating-gists)。
