title: 通用设置
description: 配置 drawDB 自动保存、表宽度、语言、自定义数据类型、本地备份、缓存与浏览器图表存储。
---

打开 `Settings`（设置）菜单可以修改开源版编辑器中跨图表生效的偏好。这些偏好存储在浏览器的 localStorage 里。

## 可用设置

| 设置项 | 作用 |
| --- | --- |
| 显示修改记录 | 在当前编辑会话中显示撤销历史。 |
| 自动保存 | 启用或关闭图表的自动保存。 |
| 表宽度 | 渲染表时使用的默认宽度。 |
| 语言 | 切换编辑器的界面语言。 |
| 配置自定义类型 | 创建在编辑字段时可用的本地数据类型别名。 |
| 导出已保存数据 | 下载浏览器本地 drawDB 数据的备份。 |
| 清除缓存 | 清除编辑器使用的应用缓存数据。 |
| 清空存储 | 不可恢复地删除 IndexedDB 中本地保存的图表与模板。 |

<Callout title="清空存储前请先备份" type="warn">
  在清空存储或清理浏览器站点数据前，请先导出要保留的图表与模板。浏览器本地数据不会自动跟随你到其他浏览器或设备。
</Callout>

## 设置与图表数据的区别

编辑器偏好与自定义数据类型别名存在 localStorage；图表与自定义模板则单独存在 IndexedDB。清掉其中一个区域的数据，可能不会清掉另一个。
