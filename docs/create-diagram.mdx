## 选择数据库

选择与目标匹配的数据库方言：

- Generic
- MySQL
- PostgreSQL
- SQLite
- MariaDB
- Microsoft SQL Server
- Oracle SQL (Beta)

选择具体数据库后，图表会展示该方言自带的类型与能力。Generic 图表则使用可移植的类型集合，可以导出为多种 SQL 方言。

## 添加表与列

从侧栏或工具栏添加一张表，给它命名，然后定义其中的列。

<ThemedImage
  lightSrc={defineTablesLight}
  darkSrc={defineTablesDark}
  alt="在 drawDB 中给表添加列"
/>

对每一列你可以配置：

- 名称与数据类型
- 主键、唯一、非空约束
- 自增（如果支持）
- 默认值与 CHECK 表达式
- 注释
- PostgreSQL 中的数组维度
- MySQL 和 MariaDB 中的无符号数值类型

<Callout title="复合主键">
  把多列同时标记为主键，会在生成的 SQL 中产出复合主键。
</Callout>

<Callout title="CHECK 约束" type="warn">
  CHECK 表达式会按原样写入生成的 SQL。请使用目标数据库支持的语法。
</Callout>

### 索引与唯一约束

索引可以包含一个或多个列，可以命名或设为唯一。表也可以定义命名的、多列的唯一约束。PostgreSQL 图表还额外支持表继承。

## 创建关系

从外键列上的蓝色连接点拖到被引用的列。两端的字段类型必须兼容。drawDB 会根据主键 / 唯一约束推断基数，之后你也可以再调整。

<ThemedImage
  lightSrc={createRelationshipLight}
  darkSrc={createRelationshipDark}
  alt="在 posts.user_id 和 users.id 之间建立关系"
/>

示例中 `posts.user_id` 引用了 `users.id`。打开 Relationships（关系）标签可以修改关系名、交换外键 / 主键端、配置一个或多个字段组合以及多端的标签。

`ON DELETE` 与 `ON UPDATE` 都支持：

- No action（无动作）
- Restrict（禁止）
- Cascade（级联）
- Set null（置空）
- Set default（置默认值）

## 组织画布

### 主题区域

从侧栏或工具栏添加主题区域，把相关的表在视觉上归类。主题区域能改善导航，但**不会**生成 SQL。

### 注释

用注释直接在图表上记录需求、决策或提醒。

## 自定义类型与枚举

PostgreSQL 与 Generic 图表暴露一个 Types（类型）标签，用来定义图表级的复合类型。PostgreSQL 图表还会暴露 Enums（枚举）标签。创建好类型或枚举后，在给列选数据类型时就可以选择它们。

Settings 菜单也允许你配置本地自定义数据类型别名。这些别名保存在浏览器中，与图表级的复合类型是分开的两套机制。
