在下表中看到 `Ctrl/Cmd` 时，Windows / Linux 用 Ctrl，macOS 用 Command。

## 文件与编辑

| 快捷键 | 操作 |
| --- | --- |
| Ctrl/Cmd + S | 保存图表 |
| Ctrl/Cmd + Shift + S | 另存为 |
| Ctrl/Cmd + O | 打开图表 |
| Ctrl/Cmd + I | 打开导入对话框（支持 JSON、DDB、DBML 或 SQL） |
| Ctrl/Cmd + C | 复制选中元素 |
| Ctrl/Cmd + V | 粘贴 |
| Ctrl/Cmd + X | 剪切选中元素 |
| Ctrl/Cmd + D | 克隆选中元素 |
| Delete / Backspace | 删除选中元素 |
| Ctrl/Cmd + E | 编辑选中元素 |
| Ctrl/Cmd + Z | 撤销 |
| Ctrl/Cmd + Y | 重做 |

## 画布与视图

| 快捷键 | 操作 |
| --- | --- |
| Enter / Return | 重置画布视图 |
| Ctrl/Cmd + Alt + W | 自适应窗口 |
| Ctrl/Cmd + ↑ 或 Ctrl/Cmd + 向上滚轮 | 放大 |
| Ctrl/Cmd + ↓ 或 Ctrl/Cmd + 向下滚轮 | 缩小 |
| 滚轮 | 垂直滚动 |
| Shift + 滚轮 | 水平滚动 |
| Ctrl/Cmd + Shift + G | 显示 / 隐藏网格 |
| Ctrl/Cmd + Shift + F | 显示 / 隐藏列详情 |
| Ctrl/Cmd + Shift + M | 切换严格模式 |
| Alt + E | 打开 / 关闭 DBML 编辑器 |
| Ctrl/Cmd + Alt + C | 把图表复制为图像 |
| Ctrl/Cmd + H | 打开文档 |

<Callout title="浏览器保留的快捷键">
  部分组合键可能被浏览器或操作系统拦截。Enter / Return 用于重置 drawDB 视图，而 Ctrl/Cmd + R 仍是浏览器刷新的快捷键。
</Callout>
