## 你可以建模什么

drawDB 支持 Generic、MySQL、PostgreSQL、SQLite、MariaDB、Microsoft SQL Server 与 Oracle SQL（Beta）图表。选定具体数据库类型的图表会展示该方言自带的类型与能力；Generic 图表则面向跨方言的可移植性。

## 你的作品存储在哪里

在开源版编辑器中，图表与自定义模板使用 IndexedDB 存储在你**当前浏览器**里。清理站点数据或换浏览器前，请先把重要图表导出。
