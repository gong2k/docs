## Pro 概念

- **本地图表（Local diagram）：** 存在当前浏览器中，可以不登录就编辑，但无法被 Pro 的集成访问到。
- **云图表（Cloud diagram）：** 存在创建或上传时选定的工作区里，让 Pro 分享、版本、团队协作与 MCP 都能用。
- **个人工作区（Personal workspace）：** Solo 账户自带的私有工作区。
- **团队工作区（Team workspace）：** 带 Admin 与 Member 两种角色的共享容器，用于团队权限与实时协作。
- **公开链接（Public link）：** 一张云图表的免登录只读 URL。
- **API Key：** 用户持有的密钥，用于 MCP 与只读 schema API 的鉴权。

通用建模行为见 [创建数据库图表](/create-diagram)、[自定义编辑器](/customizing-editor) 与 [键盘快捷键](/shortcuts)。

<Callout title="云功能需要先保存图表" type="info">
  Pro 的分享、版本历史、协作与 MCP 都跑在云端副本上。AI 助手也能在已打开的本地图表上运行（前提是账号有相应权限），但它仍然会把当前 schema 作为上下文发给 AI 服务。
</Callout>
