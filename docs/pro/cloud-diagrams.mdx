drawDB 可以在同一个编辑器里同时展示浏览器本地与云端备份的图表。搞清楚当前打开的是哪一份，能避免分享与访问上的意外。

## 本地与云端图表

|  | 本地 | 云端 |
| --- | --- | --- |
| 存储位置 | 当前浏览器 | 选定的 drawDB 工作区 |
| 是否需要账号 | 否 | 是 |
| 在其他设备可访问 | 否 | 是，前提有访问权限 |
| 公开分享 | 仅开源版快照分享 | Pro 公开链接 + 团队访问 |
| 版本历史与 MCP | 否 | 是（前提有匹配的套餐） |
| AI 助手 | 是（前提登录账号有云端权限） | 是（前提有匹配的套餐） |
| 实时协作 | 否 | 仅团队云图表可 |

用 **File → Open** 可以同时浏览两个来源。列表中会标注 Local 与 Cloud，并提供搜索、排序、数据库、来源、所有权筛选。

## 把本地图表搬上云

打开本地图表，在云端提示里选 **Move**。drawDB 会先把它上传到当前工作区，再把编辑器切到云副本。

写入完成前请不要关闭页面；如果写入失败，本地图表仍是你的兜底。

## 云保存的行为

云端的改动是**串行**保存的。如果编辑动作很快，drawDB 会把待写的内容合并提交，而不会用重叠请求打架。**Last saved**（最近保存）只有当云写入完成后才会刷新。

写动作还在进行而你想离开页面，浏览器可能会给警告。能等就尽量等写入完成。

<Callout title="重要的图表也要再导出" type="info">
  云存储能防止浏览器数据丢失，但在做大量改动、变更访问、移交账号之前，仍建议用 JSON / DDB 另存一份备份。
</Callout>

## 工作区范围

当前工作区决定：

- 普通列表里能看到哪些云图表。
- 新建云图表会落在哪里。
- 切换工作区后，会打开哪个工作区最近编辑过的图表。
- 适用的团队成员关系与分享规则。

图表属于它所在的工作区，**不是**永久属于创建者。如果创建者后来退出该团队，访问会按剩余的团队成员与权限走。

## 打开一张云图表

- 登录后访问 `/editor` 会打开你能访问的最近修改过的云图表。
- 用 **File → Open** 可以选其他图表，并查看其来源与所有者。
- 切换工作区会打开该工作区最近的图表；工作区为空时打开空白画布。
- 直接用图表 URL 打开，如果你仍属于该图表对应的工作区，工作区也会被同步切到对应那条。

## 只读云访问

当你的权限是 **Can view**（仅查看），或你的套餐已不再允许写云端时，图表会以只读模式打开。

只读模式下你可以浏览图表，但所有依赖写操作的功能都不可用：保存、修改分享设置、用 AI、创建 API Key、加入实时协作房间。

试用或订阅结束后，云端数据仍然保留；恢复匹配权限的套餐后，可写功能会自动恢复。

## 删除一张云图表

图表创建者与团队 Admin 在仍是该图表所在工作区成员时，可以管理与删除该云图表。删除会让所有能访问它的人都看不到，所以在 schema 以后还可能用上的情况下，请先导出备份。
