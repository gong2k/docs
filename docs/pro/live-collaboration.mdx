实时协作让有资格的 Team Pro 成员共同编辑同一张云图表。该功能在图表打开时会自动启动——**没有**单独的开关。

## 必备条件

每位协作者都需要：

- 是该图表所在团队工作区的成员。
- 对该图表拥有 **Can edit**（可编辑）权限。
- 一个启用了实时协作的 Team Pro 工作区。
- 是**云端备份的图表**，而不是本地图表或模板。

Pro Solo 用户、只读成员和公开链接访客都不会加入实时编辑房间。

## 协作者能看到什么

- 其他在线用户的存在头像。
- 在画布上移动的远程光标。
- 别人在连接列时画出的关系线。
- 同事创建、修改或删除受支持元素时的 schema 改动。

每个浏览器仍然把共享的图表保存到云端。实时服务负责中转操作与存在信息，并不会取代云端持久化。

## 连接状态

你头像上的小圆点显示实时会话状态：

| 颜色 | 含义 |
| --- | --- |
| 绿色 | 实时协作已连上。 |
| 琥珀色（橙黄） | drawDB 正在连接，或在等图表首次云保存完成。 |
| 红色 | 因访问权限、套餐、网络或服务配置不可用。 |

悬停圆点可以看到更具体的信息。

## 启动一次会话

1. 在 Team 工作区里打开一张已保存的图表。
2. 确认你的权限是 **Can edit**。
3. 等头像圆点变绿色。
4. 把该图表的常规 URL 分享给另一位拥有编辑权限的团队成员。

新创建的图表在首次云写入完成前会一直显示琥珀色。

## 持久化机制

连上的协作者之间会即时交换操作。一个已存在的活动房间里，新加入的人会从别人那里拿到当前场景；之后每个编辑器还是会按正常云保存路径写入文档。

两个人几乎同时修改同一个元素时，**最后一次成功写入**会决定存储的结果。建议对破坏性或大型的 schema 改动进行协调，并先记录一条 [手动版本](/pro/version-history)。

## 状态点排错

- **套餐未包含：** 必须有 Team Pro；套餐变更后请刷新账号信息。
- **你没有可编辑权限：** 让创建者或团队 Admin 给你 **Can edit**。
- **图表没存在云端：** 把图表移过去或保存，并等首次写入完成。
- **连不上协作服务：** 检查网络，刷新后重试。
- **服务端不可用或没配：** 普通云编辑也许仍能工作，但实时在线状态不会。这种情况稍后再试或联系支持。

如果图表云保存指示器已经走完，但圆点还是琥珀色，请刷新图表再升级处理。
