即使不登录账号也可以开始建模，等真正要用到云功能时再登录。Pro 的编辑器体验与开源版完全一致，原有的建模与导入流程照常可用。

## 1. 登录

打开 [drawDB 编辑器](https://www.drawdb.app/editor)，点击右上角的头像，选 **Sign in**（登录）。可用方式：

- Google
- GitHub
- 邮箱加 6 位验证码

新账号会被引导走一段简短、可选的 onboarding 流程。Team 套餐的注册还会要求你为第一个团队工作区起名。

有关验证码与 OAuth 的问题，请见 [账号与登录](/pro/account)。

## 2. 理解你的工作区

每张云图表都属于某个工作区。

- **个人工作区**用于你自己的 Pro Solo 图表。
- **团队工作区**放给该团队成员共享的图表。

如果你的账号同时属于多个工作区，可用图表标题旁边的"工作区选择器"切换。切换工作区会打开该工作区中最近修改过的图表；如果该工作区还没有图表，就打开一张空白画布。

<Callout title="工作区选择会影响新建图表" type="warn">
  创建或导入图表前请先确认当前工作区。云图表会被保存到该工作区，访问权限也按其成员关系走。
</Callout>

## 3. 创建或导入图表

新建空白图表、从模板开始、或导入 SQL / DBML / JSON / DDB。完整工作流参见 [创建数据库图表](/create-diagram)。

当你登录且云端访问可用时，新保存的图表就会落到当前工作区。编辑器会跟踪云端写入的进度，并展示最新的保存状态。

## 4. 把已有的本地图表搬上云

当打开的是浏览器本地的图表，drawDB 会弹出提示：

> 此图表存储在您的浏览器本地。要将其移至云端吗？

选 **Move**（移动）。drawDB 会把图表上传到当前工作区，写入成功后再把编辑器切到云端副本，云端独有功能随即启用。

你也可以通过 **File → Open** 看到本地与云图表混合的列表，来源标签与筛选器可以帮助区分。

## 5. 确认云副本正常

在分享或接入集成前请确认：

1. 等待保存指示器走完。
2. 打开 **File → Open**，确认该图表被标记为 **Cloud**。
3. 检查图表标题旁边显示的工作区与你预期一致。
