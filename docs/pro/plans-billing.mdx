drawDB 把面向个人的云功能与团队协作分开。当前价格与权益是动态加载的，请以 [价格页](https://www.drawdb.app/pricing) 和 **Settings → Billing**（设置 → 账单）作为你账户的最终依据。

## 套餐对比

| 能力 | Free | Pro Solo | Pro Team |
| --- | :---: | :---: | :---: |
| 本地图表与核心编辑器 | ✓ | ✓ | ✓ |
| 云存储与同步 | — | ✓ | ✓ |
| 公开只读分享 | — | ✓ | ✓ |
| AI 助手 | — | ✓ | ✓ |
| 版本历史与迁移 | — | ✓ | ✓ |
| API Key 与 MCP | — | ✓ | ✓ |
| 团队工作区、角色与权限 | — | — | ✓ |
| 实时协作 | — | — | ✓ |

  套餐功能可能与本文档独立更新。购买决策的权威依据是价格页和你账户内的套餐概览。

## 开通套餐或试用

在 Pricing 页面选套餐，并在弹窗中登录。新付费账号可能会先进入试用再结账。具体试用时长以产品内当前展示为准。

Team 套餐的 onboarding 会要求你给团队起名。Team 套餐按用户数计费。

## 完成结账

结账由 Paddle 提供，使用登录账号的邮箱。drawDB 在收到账单确认后再开通套餐。

激活通常会自动完成。如果成功页面一直停在 **Activating your plan…**：

1. 等激活检查跑完。
2. 刷新账号或重开编辑器。
3. 看看 **Settings → Billing**。
4. 如果还是没出现新套餐，联系支持。

在首次激活还在处理中时，不要重复提交付款。

## 进入账单

点头像 → **Manage account** → **Billing**。

Billing 会列出当前套餐、试用或续费状态、包含的功能，以及绑定到你管辖的工作区上的订阅。因为订阅按工作区隔离，**只有**该工作区的 Admin 才能管理相应订阅。

## 团队席位

Pro Team 按活跃成员数计费。添加或删除活跃成员会修改 Paddle 订阅的数量，可能立即产生按比例的小计调整。

去 **Settings → Teams** 管理席位。删除成员前，请先确认其集成或工作是否需要交接。**最后一个 Admin 不能被删除或降级**。

## 取消订阅

具备资格的 Admin 打开订阅的操作菜单，选 **Cancel subscription**。取消会安排在当前计费周期结束时生效，而不是立即生效。

- Pro 权限可以继续用到显示的结束日。
- Billing 会把订阅标记为"ending"。
- 周期结束时，工作区会回到非 Pro 状态，除非重新订阅。

在结束日前用 **Resubscribe** 可以恢复不断档。

## 当试用或套餐结束时

云图表**不会被删除**。工作区对 Pro 的写功能会变成只读：

- 已有可访问的图表仍可打开。
- Schema 编辑与云写入被禁用。
- 分享变更、AI、新建 API Key、实时编辑均不可用。
- 已有的 API Key 仍可列出与撤销，但只读 schema API 需要云端权限。
- 升级后会恢复 Pro 写功能，图表不会被重建。

## 账单功能限制

当前的 Settings 界面没有提供：发票历史、修改支付方式、任意切换套餐，或通用的客户门户入口。如果在 **Settings → Billing** 里找不到你要的账单操作，请联系 drawDB 支持。
