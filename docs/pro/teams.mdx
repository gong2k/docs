Pro Team 把云图表组织在共享工作区里。每个工作区都有自己的成员、角色、图表、权限与订阅上下文。

## 个人与团队工作区

- **个人工作区**是私有的，不能邀请成员。
- **团队工作区**支持成员、角色、图表权限与实时协作。

用图表标题旁的"工作区选择器"切换活动工作区；用 **Settings → Teams** 在不打开图表的情况下查看或管理某个工作区。

## 团队角色

| 能力 | Admin | Member |
| --- | :---: | :---: |
| 查看团队详情 | ✓ | ✓ |
| 打开自己有权限的图表 | ✓ | ✓ |
| 改团队名 | ✓ | — |
| 邀请别人与撤销邀请 | ✓ | — |
| 改成员角色 | ✓ | — |
| 删除成员 | ✓ | — |
| 管理团队里的每张图表 | ✓ | — |
| 管理团队的订阅与席位 | ✓ | — |

**最后的 Admin 不能降级或删除**。需要变更时先把另一个 Admin 任命好。

## 邀请同事

Admin 可以从 **Settings → Teams** 或某张图表的 Share 面板发起邀请。

1. 打开 **Settings → Teams**。
2. 输入对方邮箱。
3. 在可选的地方选 **Member** 或 **Admin**。
4. 发送邀请。

邀请 7 天后过期，且绑定到那个被邀请的邮箱。收件人必须用该邮箱**精确**登录。

<Callout title="Share 面板的邀请也是加团队" type="info">
  从某张图表的 Share 面板邀请某个邮箱，是工作区邀请——**不是**只给那一张图表的访问权。等对方接受成为团队成员后，再单独配置对那张图表的权限。
</Callout>

## 接受邀请

收件人通过邮件里的链接就能接受。未处理的邀请也会出现在 **Settings → Teams**，并带一个 Teams 标签徽章。

接受后，drawDB 会切换进新加入的工作区，并打开该工作区中最近的图表；如果该工作区还没有图表，则打开空白画布。

如果接受失败：

- **邀请过期或被撤销：** 让 Admin 重新创建邀请。
- **邮箱不对：** 登出后用被邀请的邮箱重新登录。
- **已经是成员：** 直接切换到对应工作区，不要再次接受。
- **找不到邀请：** 让 Admin 重新发一次链接。

已发出的邀请没有"重发"按钮。投递失败时，撤销它再重新邀请。

## 管理成员

在 **Settings → Teams**，Admin 可以：

- 改团队名。
- 把 Member 升为 Admin。
- 当仍有另一位活跃 Admin 时，可以把 Admin 降为 Member。
- 删除成员。
- 撤销未接受的邀请。

删除成员会立即撤销该成员对该团队图表的访问权。删除前请检查该成员的图表权限与正在生效的集成。

## 席位与账单

Team 套餐按活跃成员数计费。增减活跃成员会修改 Paddle 订阅的数量，可能立即产生按比例调整。

团队试用期间，活跃成员与未处理的邀请**都**计入试用席位上限。如果团队席位已满，先撤销未使用的邀请，再邀请新成员。

订阅管理见 [套餐、试用与账单](/pro/plans-billing)。

## 切换工作区

点图表标题旁的当前工作区，选另一项。drawDB 会：

1. 切换后续云端请求使用的工作区。
2. 打开所选工作区最近修改过的图表。
3. 若该工作区没有可访问的图表，则打开一张空白画布。

在新建图表或把本地图表移到云端之前，请先确认工作区。
