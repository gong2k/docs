根据下面的"症状"开始排查。在执行可能替换 / 删除数据的恢复步骤之前，请先保留一份导出的图表。

## 账号与验证

| 症状 | 操作 |
| --- | --- |
| 验证邮件未到 | 确认地址、检查垃圾箱、等到 **Resend code**、再申请新码。 |
| 验证码错误或过期 | 只用最新的验证码。等倒计时结束再申请。 |
| 验证尝试次数过多 | 停下来等鉴权冷却，再继续。 |
| OAuth 链接过期 / 被拒 | 回到 drawDB 重新登录，不要复用旧 callback URL。 |
| GitHub 登录说没已验证邮箱 | 在 GitHub 添加并验证主邮箱，或改用邮箱 / Google 登录。 |

参见 [账号、个人资料与登录](/pro/account)。

## 云图表与访问

### 图表仍是 Local

登录后打开它，在云端横幅里点 **Move**。先确认目标工作区，再等保存状态走完。

### 云保存失败

保持当前标签页开着，检查网络，然后做一次小改动重试。如果一直报错，请把图表导出到本地。**不要**假设没保存的改动已经上云。

### 图表只读

你的成员权限或当前套餐不允许写。请让创建者或团队 Admin 把权限改为 **Can edit**；若整个工作区都只读，就去 **Settings → Billing** 检查。

### 图表属于你已不在的团队

让那个团队的 Admin 重新邀请正确账号。云端访问跟着当前的团队成员走。

## 分享

| 症状 | 解决方式 |
| --- | --- |
| 分享控件说图表未保存 | 把它移到云端，等保存完成。 |
| 分享控件说图表为空 | 至少加一张表。 |
| 普通复制链接拒绝访问 | 确认对方已登录、属于团队并具备图表访问权限。 |
| 公开链接需要停用 | 撤销或关闭公开分享，只把替换链接发给目标人。 |
| 成员没法编辑 | 把他的权限改成 **Can edit** 并确认图表的受众允许编辑。 |

参见 [分享 Pro 图表与管理权限](/pro/sharing-permissions)。

## 团队邀请

| 错误 | 处理 |
| --- | --- |
| 邀请过期或被撤销 | 让 Admin 重新创建邀请。 |
| 用被邀请的邮箱登录 | 登出，用被邀请地址重新登录。 |
| 已经是成员 | 直接切换工作区，别再次接受。 |
| 团队试用席位已满 | 撤销未使用的邀请或删掉闲置成员。 |
| 邀请邮件未送达 | 撤销该邀请，再用同邮箱重新邀请一次。 |

## 实时协作

- **琥珀色圆点：** 等待首次云保存或连接尝试。
- **红色 — 套餐不支持：** 当前工作区没有 Team Pro 协作。
- **红色 — 无权限：** 账号没有编辑权限。
- **红色 — 不在云端：** 先把图表移过去或保存。
- **红色 — 网络 / 服务：** 检查连通性后重试一次；普通云编辑也许仍可用。

参见 [实时协作](/pro/live-collaboration)。

## 版本与 AI

| 症状 | 处理 |
| --- | --- |
| **Record version** 不可点 | 把图表保存到云端，并确认你有编辑权限与有效的 Pro 套餐。 |
| "You have no changes to save." | 当前 schema 跟最近记录的版本一致。 |
| 迁移没有 SQL | Generic 图表只支持 JSON 比对，或没有结构性 schema 改动。 |
| AI 提示要打开已保存图表 | 把当前画布保存成本地或云图表，让它有 ID。 |
| AI 请求被锁 | 登录或恢复有效云端权限。 |

## 账单激活

如果结账一直挂着：等激活检查跑完、重开编辑器、检查 **Settings → Billing**。在确认第一次付款确实失败之前不要重复结账。激活仍未出现就联系支持。

## API Key 与 MCP

MCP 的常见错误见 [用 MCP 连接 drawDB 与 AI 工具](/pro/mcp#troubleshooting-mcp)。Key 丢失或泄露时：创建替换 Key → 更新客户端 → 验证 → [删掉旧 Key](/pro/api-keys#revoke-a-key)。

## 联系支持

打开账号 Settings 对话框，选 **Community** 查看可用的 drawDB 链接。报告问题时附上：

- 工作区与图表名（**不要**贴 API Key 或私密分享 token）。
- 屏幕上显示的完整错误信息。
- 图表是 Local 还是 Cloud。
- 浏览器与操作系统。
- 问题发生的近似时间。
