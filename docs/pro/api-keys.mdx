---
title: 创建与管理 drawDB API Key
description: 为 MCP 客户端等集成创建、改名、轮换、过期与撤销 drawDB Pro API Key。
---

API Key 让脚本与集成可以代表你的 drawDB 账号行动。**当前只读 API** 由 [drawDB MCP 服务](/pro/mcp) 使用。

<Callout title="把 Key 当密码管" type="warn">
  Key 可以发现你所属团队内的云图表元数据，并能读取通过访问检查的 schema。**永远不要**把 Key 提交进代码库、贴在对话里、或给其他人。
</Callout>

## 创建 Key

1. 打开 drawDB 编辑器并登录。
2. 点你的头像，再选 **Manage account**（管理账号）。
3. 打开 **API keys**。
4. 点 **Create key**。
5. 给它取个易于识别的名字，例如 `MCP on work laptop`。
6. 选择过期时间：30、60 或 90 天；一年；或不过期。
7. 创建并**立刻复制完整 token**。

新 Key 默认 30 天过期。名字最多 80 个字符。

<Callout title="Token 只显示一次" type="warn">
  drawDB 只保存 token 的哈希，不存完整 token。如果关闭创建对话框前没保存 token，请创建替换 Key；原始值无法找回。
</Callout>

Key 以 `ddb_` 开头。API Key 列表中只会展示前缀、过期时间和最后使用时间，便于识别而不暴露 Key 本身。

## 改名

点 Key 旁边的操作菜单选 **Edit**。改名只修改标签；不轮换 token，也不改过期时间。

## 轮换 Key

按下面这个流程替换 Key 而不影响集成：

1. 创建替换 Key。
2. 更新所有用到旧 Key 的客户端。
3. 确认替换 Key 能连上。
4. 删掉旧 Key。

## 撤销 Key

1. 打开 Key 的操作菜单选 **Delete**。
2. 在确认框里输入 `DELETE`。
3. 点 **Delete key**。

撤销立即生效。任何还在用这个 Key 的客户端都会停止鉴权。

## 理解 Key 的可见性

API Key 绑定到**你的用户账号**，而不是编辑器里当前选中的工作区。

- `list_diagrams` 可能暴露你所属每个团队的图表 ID、名字、方言、更新时间。当前版本里，这个列表可能包含某个 schema 读取稍后会被 "Invite only" 或 "No access" 规则拒绝的图表。
- 切换工作区**不会**把 Key 的可见范围限定到该工作区。
- 每次 schema 请求都会重新做一次权限检查；移除访问后，schema 也会被屏蔽，即使摘要还出现在列表里。
- 仅本地的开源版图表不会通过 API 暴露。
- 创建或改名 Key 需要套餐内有效的云存储权限。
- 即使套餐或试用到期，你仍然可以删除 Key。

按最小权限原则，建议为集成专门创建一个 drawDB 账号，仅把你需要的那个工作区给它。

## 选择过期时间

建议选**尽量短**的可用期限。永不过期的 Key 减少了运维，但一旦泄露影响更大。**Last used**（最后使用）字段能帮你识别长时间没人用的 Key，再去撤销。
