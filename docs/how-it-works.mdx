drawDB 开源版编辑器是一个基于 React + Vite 的应用。它的状态由 React Context 维护，并未使用独立的 Redux 或 Zustand。

## 编辑画布

画布是受指针事件驱动的 SVG 表面。表、主题区域、注释的大部分文本内容都通过 SVG `foreignObject` 元素渲染；关系连线则是根据所连字段的位置和尺寸实时计算出的 SVG 路径。

这种结构让 drawDB 可以把熟悉的 HTML 控件与可缩放、可平移的图表表面合二为一。

## 浏览器持久化

开源版的图表与自定义模板通过 Dexie 存入 IndexedDB。编辑器偏好、自定义数据类型别名、版本缓存信息则存放于 localStorage。

由于这些数据绑定在某个特定的浏览器配置档上，清理站点数据、重置浏览器或更换设备**前**，请先把重要图表导出。

## 分享

开源版 "Share" 操作会把当前图表的 JSON 发布为一个私有 GitHub Gist。收到链接的人打开后，会加载该快照并在本地**副本**中打开——它不是实时同步通道。

## 导入

drawDB 可以导入：

- drawDB JSON 与 DDB 文件
- DBML
- SQL（MySQL、PostgreSQL、SQLite、MariaDB、Microsoft SQL Server、Oracle SQL）

SQL 源会先被解析成 AST，再转成 drawDB 的表、字段、索引、枚举、类型与关系（前提是源方言提供了足够信息）。

## 导出

编辑器可以把图表导出为：

- SQL
- PNG、JPEG、SVG、PDF
- drawDB JSON
- DBML
- Mermaid
- Markdown

SQL 输出用按方言分开的生成器；图像与文档格式基于已渲染的图表，并借助特定的序列化或导出库生成。

## 国际化

界面字符串存放在 drawDB 仓库的 `src/i18n/locales` 目录下。新增语言需要：

1. 基于 [en.js](https://github.com/drawdb-io/drawdb/blob/main/src/i18n/locales/en.js) 创建一个翻译过的 locale 文件。
2. 在 `src/i18n/i18n.js` 里 import 这个 locale。
3. 把 locale 加入语言列表。
4. 在 i18next 的 resources 表里注册。

## Pro 版架构

drawDB Pro 在同一个核心编辑器之上，又叠加了认证、团队、云图表存储、权限、计费、AI 工具与实时协作能力。这些服务独立于上面提到的浏览器本地持久化与 Gist 分享。
